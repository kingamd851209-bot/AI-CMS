# 基础 CMS 数据库

`init_database.sql` 只用于新建空库，包含重建表语句，禁止用于升级现有业务库。执行前确认数据库地址和名称，并备份已有数据；应用不会自动执行初始化或迁移。

基础初始化保留通用表结构、语言、字段目录和系统菜单。不再内置客户账号、历史访问数据、环境选项、三一站点或产品初始化任务；集团 SSO、MKP、产品初始化和网点同步专用脚本已移出基础源码。通用字段槽、多站点、表单、内容历史和运营任务表仍保留。

新环境步骤：

1. 新建独立 MySQL 库，以 UTF-8 导入 `init_database.sql`，遇错即停止。
2. 运行 `python database/create_admin.py /安全目录/create-admin.sql`，交互输入初始密码；脚本使用现有 SM3 v1 算法，不连接数据库，不写明文密码，不覆盖已有输出文件。Python 的 OpenSSL 必须支持 SM3。
3. 审核后仅在新建空基础库执行生成的 SQL。已有用户或管理员组时不要执行该脚本，不要使用忽略错误的客户端选项。执行完后删除生成的 SQL。
4. 如设置了 `CMS_PASSWORD_PEPPER`，生成管理员和运行 CMS 必须使用相同值。通过外部 Spring 配置设置数据库凭据、Redis、上传目录、AI 加密主密钥等，不使用源码中的空密码示例直接部署。

`supera`/ID 13 是现有平台管理员约定，初始化不会沿用任何客户密码。当前本机试点库已有管理员和测试站点，不需要重新初始化。

## 既有库升级

本轮没有删除既有数据库里的客户表或业务记录。旧表可保留用于回退，但基础版代码不再查询 MKP、产品初始化或客户网点同步表。清理既有客户数据需另行核对使用方和备份，不能用初始化脚本代替迁移。
