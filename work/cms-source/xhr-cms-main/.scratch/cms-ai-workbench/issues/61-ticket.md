# 61 — 续核大站并关联独立部署签收版本

**审查编号** C4、C5

**优先级** P2

**状态** 有界续核和本机独立部署回读通过隔离验收，超出规模上限的增量核验见 64 号工单

## 问题与依据

整站核验将检查数达到 200 视为仍有待处理项，缺少同版本续核。独立签收回读仅检查页面摘要，样式、脚本或媒体变化时，历史结果可能被当作当前部署结果。见 `cms-site/src/main/java/com/xinhongru/cms/template/WorkbenchReleaseReviewService.java:390`、同文件第 1717 行和外层工作区 `work/cms-local/verify-static.py:148`。

## 修改范围

- 按尚未核验的正式记录判定是否截断。沿用站点、页面包、结构、导航和部署范围校验，将续核位置绑定本次版本并汇总同版本各批结果，任意范围变更时重新核验。
- 初次独立核验保存核验时刻、清单身份和产物证据。回读时检查当前部署是否仍对应当时清单和产物；包括仅替换资源且清单没有同步更新的情况。页面展示历史通过与当前待核状态，历史记录可以回看。

## 回归验收

- [x] 隔离回归覆盖 199、200、201 条检查项。前两组无剩余，201 条可在同一范围续核并汇总。
- [x] 正式签收接口拒绝与已核批次不符的包、结构、导航、部署方式及站点。普通角色受控拒绝，同站已授权的第二位审核人可接续同一范围。
- [x] 独立部署页面摘要保持不变，分别替换样式、脚本和媒体并沿用旧清单。历史通过继续可读，当前部署待核，复核后状态对应文件结果。

留证保存分页检查数、修订、清单摘要及资源前后摘要，附签收历史与当前状态截图。C4 可先实施。C5 复用审查 B4 的正式页面集合和清单核验规则，以获得完整的当前独立部署签收。
